# 文档

这里收录带 NixOS、Home Manager 或 nix-darwin 模块的软件包。Flake 接入和二进制缓存写在仓库根目录的 `README.md`。

## Applications

- [Sparkle](applications/sparkle.md) 是 Mihomo 图形客户端。TUN 需要 nix-darwin 模块。
- [UU Remote](applications/uuremote.md) 是网易 UU 远程。后台服务需要 nix-darwin 模块。

### Web browser

- [Helium](applications/helium.md) 是注重隐私的 Chromium 浏览器，并提供 Home Manager 模块。

### Audio

- [Synthesizer V Studio 2 Pro](applications/synthesizer-v-studio-2-pro.md) 是歌声合成软件。安装插件需要 nix-darwin 模块。

## Server

### Web applications

- [Vocat](server/vocat.md) 是蜂窝模组的 Web 控制台，用 NixOS 模块安装。

## Networking

- [Sparkle](applications/sparkle.md) 是 Mihomo 图形客户端。TUN 需要 nix-darwin 模块。

### VPN

- [Usque](networking/usque.md) 是 Cloudflare WARP MASQUE 客户端的 NixOS 模块。软件包来自 nixpkgs。
